# Corpus provenance

이 edition은 11개 언어 각각 32개, 합계 352개 common vocabulary 항목을 새로 선택해 `src/app/utils/corpus.ts`에 작성했습니다. 화면·레이아웃·자연의 일반 명사를 중심으로 구성했습니다. 기존 private source의 한국 문학 원문 및 추출 순서는 이 사본에 포함하지 않습니다. 특정 출판물·사전·번역 corpus를 복사하지 않았습니다. first-party 선택·구성 코드는 MIT 조건입니다.

표현의 자연스러움이나 번역 품질을 평가한 언어 모델이 아닙니다. 모든 언어는 목록에서 무작위 복원 추출하며 문법 연결은 하지 않습니다. 순서를 보장하거나 중복을 제거하지 않습니다. 표시 형식 네 가지는 문장·행·문단 구분과 길이 규칙이며 문학·뉴스·광고 품질을 뜻하지 않습니다. 영어는 Latin Lorem Ipsum 대신 영어 명사를 사용합니다. 베트남어 항목 중 일부는 여러 음절을 공백으로 구분한 구입니다. 문자 수는 UTF-16 code unit이며 grapheme 수가 아닙니다.
