# 다국어 텍스트 생성기

11개 언어의 중립 어휘를 조합해 레이아웃 확인용 텍스트를 만드는 로컬 웹 도구입니다. 산문·행과 연·짧은 카피·리드의 네 가지 형식, 길이 조절, 클립보드 복사, TXT 다운로드를 제공합니다. 결과는 무작위 조합이며 자연스러운 번역·문법·독창성을 보장하지 않습니다.

## 실행

Node.js 24 이상에서 `npm ci`, `npm run dev`를 실행합니다. 개발 서버는 loopback에서만 열립니다. `npm run typecheck`, `npm test`, `npm run build`로 검사하고 `npm run preview`로 production build를 확인합니다.

## 생성 규칙

한국어·영어·스페인어·프랑스어·독일어·라틴어·러시아어·일본어·중국어·베트남어·태국어에 각각 32개 중립 어휘가 있습니다. 일본어·중국어·태국어는 공백 없이 조합하며 나머지는 어휘 사이 공백을 사용합니다. 베트남어의 한 어휘는 공백이 포함된 구일 수 있으므로 단어 수 설정은 사전 항목 수입니다. 문학 원문·시·기사에서 추출한 corpus를 포함하지 않습니다.

문단은 1–20개, 문단당 문장 1–15개, 문장당 항목 3–30개를 UI에서 설정합니다. 행과 연 형식은 연당 3–5행이며 문장 수 설정을 사용하지 않습니다. 리드는 문단당 최대 두 문장, 카피는 요청한 최소 길이를 지키면서 가능한 경우 8개 항목 이하로 생성합니다. 글자 수 제한은 JavaScript UTF-16 길이 기준이며 문장 끝을 정리하므로 제한보다 짧을 수 있습니다. 작은 어휘집에서 복원 추출하므로 긴 결과에는 반복이 생깁니다.

## 개인정보와 저장

서버·로그인·analytics·외부 API를 사용하지 않습니다. 텍스트는 현재 브라우저 메모리에서 생성됩니다. 복사는 browser Clipboard 권한이 필요하며 다운로드는 사용자가 선택한 로컬 파일입니다. 사이트 URL이 정해지지 않아 canonical·공개 배포 URL을 주장하지 않습니다.

## 출처와 검증

독립적으로 고른 어휘의 provenance는 [문서](docs/corpus-provenance.md), 검증 범위는 [validation](docs/validation.md)에 기록합니다. first-party 코드는 MIT이며 외부 컴포넌트의 원문 notice는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 보존했습니다.
